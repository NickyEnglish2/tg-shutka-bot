# Шутка-бот (tg-shutka-bot) 🐾

Небольшой интерактивный Telegram-бот с элементами геймификации и интеграцией ИИ, созданный для личного чата.

## Основные возможности

*   **Система социального рейтинга**: Бот отслеживает активность пользователей и начисляет баллы за использование определенных слов и стикеров.
*   **Голосование за рейтинг**: Участники чата могут инициировать голосование за добавление или вычитание рейтинга у других пользователей.
*   **ИИ-ассистент (Gemini/OpenAI)**: Бот может отвечать на вопросы и расшифровывать голосовые сообщения.
*   **Расшифровка аудио**: Автоматическая транскрипция и краткое содержание (суть) голосовых сообщений с помощью Google Gemini.
*   **Ежедневные отчеты**: Каждое утро (в 9:00) бот присылает сводку:
    *   Прогноз погоды (Иркутск).
    *   Случайный интересный факт.
    *   Топ пользователей по социальному рейтингу.
    *   Еженедельная статистика (по понедельникам).
*   **Админ-контроль**: Бот автоматически покидает чат, если его покидает создатель (админ).

## Стек технологий

*   **Runtime**: Node.js
*   **Language**: TypeScript
*   **API**: [node-telegram-bot-api](https://github.com/yagop/node-telegram-bot-api)
*   **AI**: [Google Generative AI (Gemini)](https://ai.google.dev/), [OpenAI SDK](https://github.com/openai/openai-node)
*   **Search**: [Tavily API](https://tavily.com/) (для поиска погоды и фактов)
*   **Database**: JSON-файл (`db.json`) с использованием `lodash` для оптимизации записи.
*   **Scheduling**: `node-cron`

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/NickyEnglish2/tg-shutka-bot.git
cd tg-shutka-bot
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
Создайте файл `.env` на основе `.env.example` и заполните необходимые ключи:
```bash
cp .env.example .env
```

**Необходимые переменные:**
*   `TELEGRAM_BOT_TOKEN`: Токен от BotFather.
*   `ADMIN_USER_ID`: ID владельца бота (для функции авто-выхода).
*   `GOOGLE_GEMINI_API_KEY`: Ключ для Gemini API.
*   `TAVILY_API_KEY`: Ключ для поиска Tavily.
*   `AI_API_KEY`: Ключ для OpenAI/OpenRouter (опционально, если используется как основной канал).

### 4. Сборка и запуск

**Режим разработки (с автоматической перезагрузкой):**
```bash
npm run dev
```

**Сборка и запуск в production:**
```bash
npm run build
npm start
```

## Основные команды

*   `/rating` — узнать свой текущий социальный рейтинг.
*   `Шутка-бот, добавь @username [число]` — запустить голосование за начисление рейтинга.
*   `Шутка-бот, отними у @username [число]` — запустить голосование за вычитание рейтинга.
